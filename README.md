# HR Analytics Dashboard

## Overview
A Tableau dashboard project focused on employee performance, training, workforce distribution, and attrition.

## Tools Used
- Tableau
- Calculated Fields
- Filters
- Data Visualization
- Dashboard

## Data Cleaning
- Checked duplicate employee records.
- Checked missing and invalid values.
- Standardized data formats.
- Validated employee, department, location, and training data.
- Verified performance and attrition values.

## Dashboard
- Employee Overview
- Department-wise Analysis
- Location-wise Analysis
- Performance Analysis
- Training Analysis
- Attrition Analysis

## Key Insights
- The dataset contains 2,500 employees.
- 1,899 employees are currently active.
- The overall attrition rate was 24.04%.
- 601 employees left the organization.
- IT had the highest number of employees among departments.
- Al Ain had the highest employee count among locations.
- The average performance score was 76.48%.
- The average training hours were 22.58.
